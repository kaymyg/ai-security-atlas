# Benchmark results

Scanner version 0.3.0, graded against 38 labelled case files in `benchmark/cases/`.
Generated by `python benchmark/run.py --write`; don't edit by hand.

**Overall:** 188 caught, 12 false alarms, 13 missed, 152 safe look-alikes left alone → precision 94%, recall 94%.

**How to read this.** *Precision* = of the times a rule fired, how often it was right. *Recall* = of the unsafe cases, how many it caught. Both are measured only on these hand-written cases, which deliberately include tricky look-alikes and known blind spots. They show where each rule stands, not how it will do on every real codebase. Rules with few cases have rough numbers.

Columns: **TP** caught correctly · **FP** false alarms · **FN** missed · **TN** safe look-alikes correctly left alone.
